ДЕФЕКТ 1
Компонент: метод trim()
Описание: метод удаляет только одиночные пробелы в начале строки, а не все подряд.
Воспроизведение: trim("    text") -> "   text" (удаляется только один пробел)
Ожидаемое поведение: удаление всех пробелов в начале строки
Критичность: средняя
Решение: заменить цикл с removeprefix на string.lstrip() или исправить логику цикла

ДЕФЕКТ 2
Компонент: метод contains()
Описание: при передаче пустой строки в качестве символа поиска метод вызывает ValueError.
Воспроизведение: contains("test", "") -> ValueError
Ожидаемое поведение: возвращать False для пустого символа поиска или явно обрабатывать этот случай
Критичность: высокая
Решение: добавить проверку на пустую строку перед поиском

ДЕФЕКТ 3
Компонент: метод delete_symbol()
Описание: проверка contains() перед заменой избыточна, так как replace() безопасно работает с отсутствующими подстроками.
Воспроизведение: delete_symbol("test", "x") -> "test" (работает корректно, но проверка не нужна)
Критичность: низкая
Решение: убрать проверку contains() и просто использовать string.replace()

ДЕФЕКТ 4
Компонент: метод capitalize()
Описание: использует встроенный метод str.capitalize(), который также делает остальные буквы строчными.
Воспроизведение: capitalize("HELLO") -> "Hello"
Ожидаемое поведение: только первая буква заглавная, остальные без изменений
Критичность: средняя
Решение: реализовать собственную логику capitalize без использования str.capitalize()
